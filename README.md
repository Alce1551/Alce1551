### `> methodology`

```text
[ AS-IS ] ──> [ DESIGN ] ──> [ DEPLOY ] ──> [ TEST ] ──> [ DOCUMENT ]
                  ↑                                │
                  └────────── [ IMPROVE ] <────────┘
```

No se trata solo de lograr que algo funcione: busco comprender **por qué funciona**, **cómo diagnosticarlo** y **cómo reproducir el resultado** con documentación útil.
